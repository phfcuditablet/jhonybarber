# Jhony Barber | Barbearia & Cuidado Masculino

Landing page moderna e responsiva desenvolvida para a barbearia **Jhony Barber**, com **Painel Administrativo** integrado que permite adicionar, editar, excluir serviços, ajustar preços e atualizar links sociais via `localStorage`.

## 📁 Estrutura de Arquivos
1. `index.html` - Estrutura principal da página.
2. `style.css` - Estilos e responsividade.
3. `script.js` - Lógica interativa, serviços e painel admin.
4. `README.md` - Documentação.

## 🚀 Publicação no GitHub Pages
1. Faça o commit e push dos arquivos para a branch `main`.
2. No repositório, vá em **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o link do seu site ser gerado!
