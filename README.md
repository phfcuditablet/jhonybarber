# Jhony Barber | Barbearia & Cuidado Masculino

Landing page institucional completa com painel administrativo em página dedicada (`admin.html`).

## Estrutura do Projeto:
- `index.html`: Página pública para clientes e visitantes.
- `admin.html`: Página administrativa para edição completa de textos, contatos e serviços.
- `style.css`: Estilização responsiva e padronizada do site.
- `script.js`: Gerenciamento dinâmico de conteúdos, persistência de dados e integração.
