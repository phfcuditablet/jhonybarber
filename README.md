# Jhony Barber | Barbearia & Cuidado Masculino

Landing page moderna e responsiva desenvolvida para a barbearia **Jhony Barber**, com um **Painel Administrativo** integrado que permite gerenciar serviços (adicionar, editar, excluir), preços e links de redes sociais diretamente no navegador utilizando `localStorage`.

## 📁 Estrutura de Arquivos
Para subir para o seu repositório no GitHub, você precisará enviar exatamente os seguintes arquivos na raiz do projeto:

1. `index.html` - Arquivo principal da página estruturado com HTML5.
2. `style.css` - Folha de estilos personalizada com layout escuro e detalhes dourados.
3. `script.js` - Lógica de interatividade, renderização dinâmica dos serviços e painel administrativo.
4. `README.md` - Documentação do projeto.

## 🚀 Como Executar
Basta clonar o repositório ou baixar os arquivos e abrir o `index.html` em qualquer navegador web moderno.
